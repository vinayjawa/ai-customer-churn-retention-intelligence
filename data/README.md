# Data directories

| Path | Purpose | Version control |
|------|---------|-----------------|
| [raw/](raw/) | Kaggle CSV copy (`WA_Fn-UseC_-Telco-Customer-Churn.csv`) | **Ignored** — download locally |
| [processed/](processed/) | EDA exports, SQL EDA CSVs, retention/score outputs | **Ignored** — regenerated by scripts |

## Privacy

- Raw and processed files contain **customer-level** records (`customerID`).
- Do not commit, upload, or paste row-level data into documentation.
- Anonymized summaries for portfolio use live under `processed/retention/` when generated by `python -m churn_intel.retention`.

## Optional root CSV

A copy at the project root may exist for convenience; `.gitignore` excludes `WA_Fn-UseC_-Telco-Customer-Churn.csv`. Prefer `data/raw/` for ingestion (`CHURN_CSV_PATH`).
